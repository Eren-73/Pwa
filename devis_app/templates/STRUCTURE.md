# Structure des Templates

## Organisation des Templates par Fonctionnalité

### 1. Devis (`templates/devis/`)
- `creer_devis.html` : Formulaire de création de devis
- `devis_template.html` : Template principal du devis
- `detail_devis.html` : Vue détaillée d'un devis
- `liste_devis.html` : Liste des devis

### 2. Clients (`templates/clients/`)
- `ajouter_client.html` : Formulaire d'ajout de client
- `modifier_client.html` : Formulaire de modification
- `client_list.html` : Liste des clients
- `client_devis.html` : Devis d'un client spécifique
- `devis_par_client.html` : Liste des devis par client

### 3. Produits (`templates/produits/`)
- `liste_materiels.html` : Liste des produits/matériels
- `modifier_produit.html` : Formulaire produit
- `modifier_categorie.html` : Gestion des catégories

### 4. Points de Vente (`templates/points_vente/`)
- Liste et gestion des points de vente

### 5. Commercial (`templates/commercial/`)
- Dashboard commercial
- Gestion des actions commerciales

### 6. Base (`templates/`)
- `base.html` : Template de base

### 7. Admin (`templates/Dashboard_Admin/`)
- `admin_dashboard.html` : Dashboard administrateur
- `403.html` : Page d'erreur d'accès
